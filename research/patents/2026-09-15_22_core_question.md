# 第22回：調査の本質的な問い

2026-09-15。これまで検討したRAG、訂正UI、対象区間指定、音素検索、辞書登録、再学習は手段であった。調査の中心を次の問いに置き直す。

> **人間が一回行った訂正は、将来のどの発話に、どの条件で、どこまで再利用してよい証拠なのか。**

## 1. なぜこれが中心か

人が認識結果 `A` を `B` に直した事実だけでは、システムは次を知らない。

| 未確定なこと | 例 |
|---|---|
| 訂正の意味 | ASR誤りの修正か、議事録向けの文章編集か |
| 音声との関係 | 元音声が本当に `B` を含んでいたか |
| 適用単位 | 一語だけか、複数語・表記・読みまでか |
| 適用条件 | 同じ話者だけか、同じ話題・文脈だけか、全利用者か |
| 適用時点 | 次の一回だけか、即時後修正か、次回モデル更新後か |
| 反証時の扱い | 後に別表記へ直されたとき、何を無効化するか |

この未確定さを解かずに、訂正を辞書追加、RAG検索、又は再学習へ直接流すと、専門語には効いても別文脈への誤置換を生む。

## 2. 各案の位置付け

| 案 | 本質的問いへの役割 |
|---|---|
| 訂正発話・対象区間指定UI | 何を直したかを取得する入口 |
| 音素検索 | 正しい語候補を得る手段 |
| RAG | 過去の訂正を現在の発話と照合する手段 |
| 部署・個人・会話文脈 | 訂正が当たりやすい条件を表す情報 |
| 候補選択・新規登録 | 訂正の正解を確定する手段 |
| 定期的なモデル更新 | 確定した訂正を長期的に反映する手段 |

これらは全部必要になり得るが、いずれも「訂正一件を再利用可能な規則に昇格してよいか」という判断そのものではない。

## 3. 今後の発明検討の単位

「用語カード」ではなく、訂正を次のような**再利用判断付きの証拠**として扱う。

| 項目 | 問いへの答え |
|---|---|
| 観測事実 | どの音声区間のASR表記が、何へ確定されたか |
| 根拠 | 人の明示選択、再発話、音声照合、文脈、外部資料のどれか |
| 許容する適用範囲 | 表記のみ、読みを含む、同一話題のみ、候補提示のみ等 |
| 反証条件 | 何が起きたら自動適用を止めるか |
| 昇格条件 | いつ候補提示から自動後修正、さらにモデル更新へ移すか |
| 失効条件 | 用語変更、誤訂正、文脈変更、撤回時にどう戻すか |

この構造を採ると、目的は「訂正をたくさん集める」ことではなく、**訂正を誤って一般化しないまま、次の適切な発話へ効かせること**になる。

## 4. 先行技術との調べ方

今後は、RAGや音素検索という名称を検索軸の中心にしない。各近接文献について、次を請求項と実施形態で照合する。

1. 訂正をどの証拠で正しいと扱うか。
2. 訂正をどの発話・話者・文脈へ再利用するか。
3. 自動修正、候補提示、辞書／モデル更新をどう切り替えるか。
4. 後の誤訂正・取消・用語変更をどう扱うか。

この比較で、既知の訂正UIや候補検索の外に、具体的な未充足点があるかを確認する。現時点では、未充足点や特許の空白は未判断である。
