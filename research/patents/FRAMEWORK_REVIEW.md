# 自動改善の枠組み：発明候補を絞るための比較

2026-09-15。ユーザーの業界・データ・実装は未確定。以下は調査者の設計仮説であり、特許の空白、新規性、効果の認定ではない。新たな公報の根拠は[第12回](2026-09-15_12_official-status-and-framework.md)、既確認公報は[請求項比較](CLAIM_COMPARISON.md)に集約する。

## 1. いま言えること

「専門語を自動発見して学習する」だけでは比較が粗い。候補発見、正誤判定、学習、採用、撤回の各工程に近い文献がある。発明を検討するなら、失敗場面を決め、その失敗を既存の仕組みではどう扱い、検討案では何を変えるのかを固定する。

## 2. 三つの検討案

| 検討する失敗 | 既存例との接点 | 具体化すべき処理 | 効果を否定しうる試験 |
|---|---|---|---|
| 同じ誤転記が複数文書へコピーされ、正解の裏付けに見える | 文書選別JP6004452B2・JP7858433B2、認識結果比較JP2012108429A | 語の観測数と元データの出所数を分け、派生文書を同じ根拠群として扱う。独立した音声／確認が得られるまで保留する条件を定義 | コピーを100件に増やしても採用判定が不当に上がらないか。別出所の正しい少数例を誤って統合しないか |
| 発話後の操作取消を認識ミスと扱い、正しい専門語を弱める | 行動から正否を推定するUS6374221B1、訂正／編集を分けるJP4657736B2 | 「認識誤り」「意図の変更」「判定不能」を分ける観測項目と保留解除条件を定義。取消だけを確定ラベルにしない | 正しく認識した後の予定変更と、誤認識による取消を混ぜ、誤学習率と保留率を比較する |
| 一件の誤った読みが辞書・合成音声・追加学習・共有へ広がる | 除外履歴JP5921601B2、リセットWO2023113422A1、学習解除US20260155138A1・US20260170341A1 | 根拠→生成データ→更新版→配布先の関係を記録。誤根拠に依存するものと別根拠でも支えられるものを分けて停止・再構築する | 誤根拠を撤回した後の残存影響と、無関係な改善の損失を測る。依存関係の記録だけで影響除去を達成したとしない |

これらの組合せ自体の既知性は未確認。特に三つ目は一般MLの学習解除文献にも近いため、「履歴を残す」「関連例を探す」だけを固有点にしない。

## 3. 比較用の最小記録案

同じ専門語でも、表記、読み、意味、適用部署が異なる可能性がある。候補1件を単なる文字列として扱わず、少なくとも以下を区別する案を比較に使う。

| 記録 | 目的 |
|---|---|
| 表記・読み候補・適用場面 | 同音異義語や部署違いを混ぜない |
| 元音声の区間、文書の版、訂正の前後 | 何を根拠にしたか監査できるようにする |
| 同じ元情報から派生した根拠の関係 | コピーや自動生成を別々の裏付けと数えない |
| 判定状態と理由 | 未確認・矛盾・評価待ち・採用を区別する |
| 生成した学習例、変更先、親版、配布範囲 | 撤回対象を追えるようにする |
| 採用前後の評価と停止後の評価 | 採用理由と回復の成否を残す |

個々の欄の保存は設計案であり、それ自体の新規性を主張していない。実際に必要な保存内容は、利用できるデータと更新方式で変わる。

## 4. 更新先ごとに「取消」を定義する

| 変更先 | 比較する撤回案 | 完了を判定する条件 |
|---|---|---|
| 辞書・文脈語リスト | 対象登録の停止と、他の根拠による登録の維持 | 問題語の誤誘導が減り、正しい既存語を損ねない |
| LLM後処理に渡す語・説明 | 根拠の無効化と参照内容の再構成 | 停止対象が残った参照情報から再投入されない |
| 音声認識モデルの重み | 原因データ除外後の再学習、適応部再構築、学習解除を比較 | 原因データの影響と無関係な性能低下を別々に測る |
| 組織への共有 | 配布先の該当版停止・代替版配布 | 対象範囲で切替を確認し、再配布を防ぐ |

モデルの重み更新は、辞書の一行削除と同じ操作で戻せるとは仮定しない。旧版への切替ができても、その後に得た正常な改善を維持できるとは限らない。

## 5. 実験を行う際の比較条件

実験は未実施。数字の目標値も未設定。以下は検証計画であり、結果ではない。

1. 更新なしを基準に、単純な出現回数・信頼度による採用と、検討案を同じデータで比較する。
2. 更新用の例と評価用の例を分け、同じ元音声・同じコピー元の文章が両側へ漏れないようにする。
3. 専門語の正答だけでなく、専門語を含まない音声への誤挿入、似た音の語、低頻度語を分けて評価する。
4. 誤った根拠を意図的に混ぜ、採用までの時間、誤採用率、保留率、撤回後の残存誤り、正常な改善の損失を測る。
5. 「出所の重複除去だけ」「保留だけ」「両方」など条件を分け、何が効果を生んだか調べる。

全体の認識誤り率が改善しただけでは、低頻度の重要語が悪化していないとは判断しない。テスト用合成音声だけで実音声への効果を認定しない。

## 6. 次の監査で見る一点

**最初に具体化するのは「何を正解の根拠とするか」。** ここが定まらないと、辞書登録・合成音声学習・LLM訂正のどれを選んでも、誤りを増幅する可能性を評価できない。業界やモデルを固定する前でも、上の三つの失敗例と記録案の妥当性は監査できる。

全体像の整理と仮説比較は作成済み。発明案の確定には、利用可能な根拠データの条件、近い公報の全項・経過、非特許文献との比較が残る。
