# 専門用語に対応する音声認識：全体像

2026-09-15更新。第一段階の全体像調査を統合。日本中心、海外参考。ユーザー監査前。

**辞書登録だけでなく、通常の訂正、文書からの収集、未ラベル音声や合成音声による学習、更新前評価、運用時の切替まで先行例があります。** 「自動改善」という目的だけでは、新しい発明かどうかは決まりません。

## どこを変えるか

| 方式 | 何をするか | 代表例 |
|---|---|---|
| 辞書 | 語と読みを足す、語を出やすくする | JP5366169B2 |
| 認識時の文脈・言語モデル | 利用場面や分野に合う候補を選ぶ | JP6233867B2、JP7858433B2 |
| モデル本体 | 音声と文字の対応を追加学習する | JP7146038B2、JP7104247B2 |
| 認識後の訂正 | 出た文章を専門語に合わせて直す | JP2025135075A |

## 自動改善の流れ

音声・文書・訂正・操作履歴 → 候補の発見 → 正しい表記・読みの裏付け → 更新案 → 副作用の評価 → 採用・適用範囲 → 運用確認・撤回

各工程の先行例と請求項は[統合レポート](LANDSCAPE_REPORT.md)に整理しました。

- 訂正と単なる文章編集を区別して学習する日本例：JP4657736B2。
- 判定の難しい音声等を選んで書き起こし・学習に回す例：JP2012108429A。
- 登録後に他の音声がどう変わるか、人が確認する例：JP6526608B2。
- 検証に失敗した入力に適応前モデルを使う海外例：WO2023113422A1。

## 今回確認できた重要な差

[JP7858433B2](https://patents.google.com/patent/JP7858433B2/en)の登録請求項1には、読み仮名から疑似認識を行い、誤りやすさを基準に表現抽出する条件があります。公開時の「分野の文書から学習文章を集める」という広い説明だけで登録範囲を捉えないよう更新しました。

[JP2025135075A](https://patents.google.com/patent/JP2025135075A/en)は、以前確認したWO2025186658A1の日本対応です。LLMにユーザー関連語と認識結果を渡す公開請求項を確認しました。

## 次に具体化する5つの問い

1. 文書・音声・訂正の根拠が矛盾したら、何を優先し、いつ保留するか。
2. 滅多に出ないが重要な専門語を、少ない証拠でどう評価するか。
3. 他の改善を残しながら、誤った更新だけを取り消せるか。
4. 個人の改善を部署や全体へ広げる条件は何か。
5. 辞書、モデル本体、後処理のどこを変えるのが適切か。

これは特許の空白の認定ではありません。[枠組み比較](FRAMEWORK_REVIEW.md)で、根拠の重複・操作取消・誤更新の波及という失敗例から処理と測定項目を具体化しました。追加調査ではASRの誤学習データ選別や一般MLの原因追跡・学習解除にも近い公開例が見つかりました。
